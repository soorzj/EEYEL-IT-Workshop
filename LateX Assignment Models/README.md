# Assignment 1 - Document Creation Using LaTeX 
Jan 15 (Edited Jan 17)


Students are requested to select one
conference paper from ICCC 2025, CET by searching IEEE Xplore
using the keyword:

“6th IEEE International Conference
on Control, Communication and Computing, Thiruvananthapuram”

Using the shared LaTeX templates,
students must prepare the following based on the same selected paper content:

* Conference paper
* Presentation
* Report
---

Students must upload three
separate .tex files along
with their corresponding PDF files to the classroom.


⚠️ Important Note:
No two assignments should be the same.
